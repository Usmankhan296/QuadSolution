🏥 QuadSolution – Medical Credentialing Website
📌 Overview

This is a fully responsive frontend website built for a medical credentialing company.
It focuses on clean design, smooth user experience, and interactive UI components.

🚀 Features
Responsive design (mobile + desktop)
Smooth scrolling navigation
Interactive services cards
Process workflow section
FAQ accordion (click to show answers)
Contact form with alert functionality
Scroll animations
Mobile hamburger menu
🛠️ Technologies Used
HTML
CSS
JavaScript
